Client Installation & Troubleshooting

Setup best practices and fixes for the most common problems. Once you have your own RoF2 client, the patcher handles nearly everything else — installing the server files, updating, and repairing them. Most issues are one File Integrity Scan away from fixed.

⬇️ Get the Game — Install with the Patcher

⚠️ You need your own RoF2 client first

We do not provide the EverQuest RoF2 (Rain of Fear) client, and we are not able to. You must source your own copy before any of the steps below will work.

The patcher updates and repairs an existing RoF2 installation — it does not download the base game.

⚡ Download PTPatcherWindows · .zip
  1. Get a RoF2 client of your own — we cannot supply one.
  2. Create a folder inside your user directory, e.g. C:\Users\<YourUsername>\Project Triune\, and put your RoF2 client in it.
  3. Unzip the download into that same folder, then run PTPatcher.exe.
  4. Pick your server, hit PATCH — it downloads and installs the server files on top of your client — then PLAY.

✅ Try this first — for almost anything

Patcher → Extras → File Integrity Scan

It re-checks every file, finds anything corrupt or missing, and turns the button into PATCH to fix exactly those files. This solves most problems on its own.

🛠 Essential Setup — Pick the Right Install Folder↑ Top

Why this matters: Windows protects system folders and many root-level directories, silently blocking custom files or forcing them read-only. Installing somewhere you have full, native ownership prevents most write errors before they happen.
✘
C:\Program Files\  or  C:\Program Files (x86)\ Restricted system folders — Windows will block or sandbox custom files.
✘
C:\Games\NMS Client\ Root-level custom folders are often protected too, and can end up read-only.
✔
C:\Users\<YourUsername>\NMS Client\  or  C:\Users\<YourUsername>\Documents\NMS Client\ Inside your personal user directory, where you have full unrestricted permissions.

🔍 Troubleshooting by Symptom↑ Top

1

Game won't start / crashes instantly

Run the File Integrity Scan. If Windows blocked your dinput8.dll (common when installing from a downloaded zip), just running the patcher clears it — no admin needed.

2

“Shortcut doesn't work” / launches then dies

You made a shortcut to eqgame.exe. Launch from the patcher instead.

3

Patcher says it can't write a file

It will tell you the reason. Usually one of:

  • Windows Controlled Folder Access (Defender ransomware protection)
  • Your antivirus
  • Client is in a protected folder → move it to C:\Users\<YourUsername>\...
  • Game still running → close it fully
4

Antivirus flagged the patcher or dinput8.dll

False positive. The patcher downloads files and modifies eqgame.exe, which looks like malware to heuristics. Add an exclusion for your client folder.

We will never ship anything that touches your antivirus settings for you.

5

Patch got interrupted

Just run it again. It resumes where it left off — it does not restart.

6

Wrong zone loading / broken graphics

File Integrity Scan.

7

Game loads but strange things happen

Are you patched to the correct server? You can't patch to Test and play on Live. Open the patcher and check whether the server you want to play on has an available patch — if it does, you were patched to the wrong server.

🎒 Looting & UI↑ Top

8

Can't loot / bard instrument in the center of your inventory

A client version mismatch or incomplete patch. Run the File Integrity Scan to repair your asset files.

9

Loot window missing or off-screen

Items drop but the loot window is nowhere to be seen — it was dragged off-screen or scaled incorrectly. In the in-game chat, type:

/nmsloot reset

This instantly returns the NMSloot window to its default position.
